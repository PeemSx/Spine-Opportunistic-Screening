# Retired XGBoost experiments

These files were removed from the active project on 2026-08-16 because the
XGBoost models did not materially improve masked vertebral height prediction
over the interpolation baseline.

The archive contains the former trainers, tests, notebooks, and generated
evaluation artifacts. It is retained only for reproducibility and can be
deleted later when the results are no longer needed.

The reusable masked-morphology dataset builder and the non-XGBoost sequence
experiment remain active in the repository.
